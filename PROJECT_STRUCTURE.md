## Naming Guide

Use `pages` for route-level UI like login, home, product details, cart, and checkout pages.

Use `widgets` for smaller reusable UI pieces inside a feature.

Use `controllers` for feature state and user interaction logic.

Use `models` for data objects used by a feature.

Use `repositories` for data access rules, such as fetching products or saving cart data.

Use `services` for external integrations, such as API clients, storage, auth providers, and analytics.

## Generated Folders

These folders are generated by Flutter or IDE tooling and should not be treated as app architecture:

```txt
.dart_tool/
.idea/
build/
```
